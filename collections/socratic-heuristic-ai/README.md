## 阅读提示

每份卡片区分论文报告、分析和研究假设，所有PDF页码都指本次下载文件的页序号。作者公开版本可能与出版排版版本存在差异，引用正式出版信息请用BibTeX。自动审计通过不等同科学结论已被独立验证。

最适合入门：SPL → DBox → SocraticLM → ScaffoldLM。算法研究可接着读MHPO、LEAP、SHAPE；评价研究可读EducationQ与StudentSimulation。具体证据强度和原文统计口径问题见横向对照。
