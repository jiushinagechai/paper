## 三条建议阅读路线

1. **从教学理念到系统实现：**SPL → DBox → Inquizzitor → ScaffoldLM。分别看场景、学习者主导权、评价证据、步骤控制如何落实。
2. **算法研究：**SocraticLM → MHPO → LEAP → SHAPE。分别对应训练数据、优化目标、动态规划、显式约束。再以 EduPlanner 对照不依赖 LLM 的教学决策路线。
3. **评价与实验设计：**BIPED → EducationQ → StudentSimulation → DBox / CodeAid。理解静态拟合、模拟教学、学生仿真和真人证据各自能支持什么。

## 从全文阅读得到的六个研究判断

- **好问题的数量不是最终目标。**需要明确当前掌握缺口、下一步局部目标和帮助强度，并检验学习者离开工具后是否能完成任务。SocraticLM、ScaffoldLM 与 SHAPE提供不同的控制点。
- **真实数据、真实使用、真实学习成效是三个层级。**BIPED来自真人对话，CodeAid观察真人使用，DBox包含无工具相似题测试；三者不能互换证据标签。
- **模拟器是训练资源，也是潜在偏差源。**MHPO/LEAP优化模拟交互，GenAL使用KT模拟器，EducationQ以模型为学生。至少应换模拟器，再做真人和迁移验证。
- **少给答案与有效帮助需要一起优化。**硬性拒答可能使学生退出；DBox允许逐步揭示，SHAPE按掌握状态分流，CodeAid暴露了准确性与挫败的实际矛盾。
- **多智能体收益需与额外预算区分。**同基座、同检索信息、同调用/token预算的对照，比只比较系统名称更有解释力。
- **指标定义必须随引用一起带走。**SocraticLM的Overall、EducationQ的ALG、GenAL的E_p、SHAPE的条件Pedagogy及ChatScratch的Dr. Scratch分数，均不等价于真人学业成绩。

## 可立项但尚未查重的候选方向

**证据驱动、可渐隐的教学控制。**以真实形成性评价估计掌握度和不确定性；在低置信时追加诊断；按认知状态选择追问、线索、例题或暂缓干预；用无工具迁移成绩而非对话成功率评估。可从 Inquizzitor + SHAPE + DBox 的机制比较出发。对照至少包含直接讲解、固定苏格拉底提示、仅状态控制、完整系统。控制模型、任务与总时间；同时测泄露、挫败、调用成本及一周后保持。以上为待检验假设，不声称创新已成立。
